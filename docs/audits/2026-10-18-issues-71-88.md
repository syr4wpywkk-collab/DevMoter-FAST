## Security invariants reinforced

- The file browser's denylist now also applies when users **type a path directly** in the preview tool; canonical destinations are checked to prevent in-root symlink aliases.
- Explicit artifact registration/download paths reject sensitive names, even when an artifact path is supplied manually.
- Artifact API JSON no longer returns absolute server output-root directories. Internal registry entries retain roots for safe resolution.
- Approved command hooks no longer inherit host API tokens or runtime-injection environment variables.
- Provider fallbacks run in the declared order. Status-less semantic errors do not silently forward a prompt to another endpoint.
- Existing registered-project checks, same-origin/auth middleware and the browser-opt-in boundary are unchanged.
