# DevMoter Base 機能トラッカー（全60機能）

開発計画書 v1.0 の60機能について、実装と検証の状況を1行ずつ記録する。機能を実装・検証した PR がその行を更新する。

状態の値:

- `未着手`: 実装なし
- `実装済み`: コードとテストがあり、CI で成功している
- `検証済み`: 計画書の完了条件を実環境で確認し、その証跡（CI 実行・手順書）を「実装・検証」列に記載している

「初期」列の ● は初期実装パッケージ（15機能）。
