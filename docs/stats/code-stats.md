# コード行数・言語別統計

`npm run stats:update` が生成するファイルです。手で編集しないでください。`npm run stats:check`（`npm run check` に含まれます）が実際のソースとの一致を確認します。

コメント行の判定は行単位の近似です。バイナリファイルはファイル数にだけ数えます。`package-lock.json` とこの統計ファイル自身は対象外です。
