# DevMoter FAST デザイン方針（unslop / 黒基調）

2026-10-29 作成。PR #479（feat/unslop-ui）の続きとして、今後のUI調整の基準をまとめる。

## 1. コンセプト

「ターミナルの隣に置いても浮かない、静かな作業机」。
主役はコード・会話・差分で、UI そのものは目立たせない。

## 2. 色

- 背景は真っ黒寄りのニュートラルグレーだけで階層を作る（紺・青みは使わない）。
  - canvas `#0a0a0a` → panel `#111111` → card `#141416` → elevated `#161618` → hover `#1c1c20`
  - 境界線は `#202022` / `#252528` の 1px のみ。影はモーダルだけ。
- アクセントはエメラルド `#10b981` 1色。使い所は「主ボタン」「選択中」「接続OK」だけに絞る。
- 状態色は error `#ef4444` / warning `#f59e0b` のみ。面全体を塗らず、ドット・文字・細い枠で示す。
- グラデーション・発光（glow）は使わない。
- ライトテーマは同じ階層をそのまま反転（既存トークン）。

## 3. 文字

- UI は Inter / system-ui、コード・数値・パスは JetBrains Mono。
- 見出しは sentence case。ALL CAPS と広い字間（letter-spacing）は使わない。
- サイズは 12 / 13 / 14 / 16 / 20 / 28 の6段に限定。本文 14px。
- 補足文は `--text-muted`、ラベルは `--text-secondary`。灰色を3段以上重ねない。

## 4. アイコン

- 24px グリッド・線幅 1.5・角丸の線アイコン（`src/line-icons.ts`）に統一。
- Unicode 記号（◇ ⌁ ☷ ⑂ ⌘ など）は端末で豆腐になるので使わない。
- アイコンは基本 `--text-muted`、ホバー・選択中で `--text-primary`。アクセント色にしない。
- テストで単体読み込みされるモジュールは import せず SVG をインラインで持つ。

## 5. 形と余白

- 角丸: コントロール 6px、パネル 8px、モーダル 12px。丸ボタン（pill）は送信ボタンなど1画面1個まで。
- 余白は 4 / 8 / 12 / 16 / 24 / 36 の刻みだけ。
- カードの中にカードを入れない。区切りは線か余白で。

## 6. 画面ごとの方向性

- **ホーム**: 「Quick actions」を4つまでに絞り、残りは Workspace 一覧へ。接続状態は上部に1行のステータスとして表示。
- **Codex / チャット**: 中央カラムは最大 760px。左サイドバー（履歴）・右パネル（セッション/ワークスペース）は同じ黒の面で、線1本で区切る。右パネルの各ボタンはアイコン＋ラベルの1行リスト化。
- **下部タブバー（iPhone）**: Tasks / Chat / Review / Tools の4つ、選択中だけ白文字＋上に2pxのアクセント線。
- **設定**: iOS 設定風のグループリスト。行頭アイコンも線アイコンに置き換える（次の作業候補）。
