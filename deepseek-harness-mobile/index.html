プライバシー

このアプリが端末に保存するのは、DSH の接続先 URL、選択したモデル、モデル一覧のキャッシュ、この端末での使用量集計だけです。DeepSeek API キーは保存せず、読み込み中のページのメモリにのみ保持します。旧版が localStorage に保存したキーはアプリ起動時に削除します。API キーは残高・モデル・チャットのリクエストと一緒に api.deepseek.com へだけ送信されます。DSH の認証情報を扱うことはありません。接続テストは認証情報なしの HEAD リクエストです。
